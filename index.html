No Name Battle Royale

In this project, I developed nearly all systems of a classic 3D battle royale game using a modular, event-driven architecture. Core gameplay features include player movement, inventory and equipment management, weapon mechanics, and animation using Unity's Animation Rigging package. I also implemented safe zone logic, dynamic loot spawning, and network synchronization using Pun2 for multiplayer functionality. The project was structured with clear separation of responsibilities, with each system handling its own logic and communicating through events, making the codebase easier to maintain and extend. Working solo on this project allowed me to gain hands-on experience integrating multiple interconnected systems and refining gameplay mechanics from start to finish.
